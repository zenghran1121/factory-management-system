# 个人项目介绍（可按实际情况修改后用于猎聘）

## 项目名称
小型工厂生产经营管理系统（Python 桌面应用）

## 项目简介
面向小型制造场景的桌面管理系统，覆盖基础资料、客户与订单、产品组件关系、月度生产计划、日排程、生产记录、库存流水、采购需求、结算记录及统计报表。

## 技术栈
Python、Tkinter/ttk、SQLite、SQL、pandas、Matplotlib、unittest。

## 个人工作与技术亮点
- 基于原有单文件应用开展渐进式重构，按业务域拆分 UI 模块，并建立独立的数据库、repository 和 service 模块。
- 统一 SQLite 连接配置，启用外键约束和 busy timeout，并使用 SQLite backup API 进行一致性备份。
- 针对生产入库设计业务服务：在同一事务中维护库存余额、库存流水和生产记录过账状态，避免重复入库。
- 将订单金额和生产排程汇总改为基于明细数据重算，降低冗余汇总值与源记录不一致的风险。
- 使用 unittest 为核心数据库行为编写自动化测试。

## 当前项目状态
个人作品集/学习型项目，已进行基础语法与数据库服务测试。完整 GUI 回归、真实历史数据库迁移验收和完整采购/发货业务闭环仍需继续完善。

## 面试中建议准备的问题
1. 为什么库存余额与库存流水需要同一事务？
2. 为什么 `stocked` 状态不能只由界面按钮控制？
3. UI、Service、Repository、数据库分别负责什么？
4. 为什么订单金额和排程数量适合从明细重算？
5. 目前采购需求算法有哪些业务数据缺口？
